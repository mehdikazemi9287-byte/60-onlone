## شصت‌آنلاین (60Online) — repo: 60-onlone (عمومی)
- مالک: ایرانیان کارنامه رادمان نوین. شاخهٔ marketplace-roadmap به main merge شد (2026-11-08).
- تمایل به مارکت‌پلیس (غرفه برای کسب‌وکارها، اعتبار، سفارش برندها) با حفظ پنل سازمانی (سازمان پک خودش را می‌سازد) و سازنده‌هایی مثل جهیزیه‌ساز؛ قبل از تصمیم تحقیق بازار. تخفیف هر کسب‌وکار روی پلتفرم، تصمیم در checkout.

### 70online MVP
- مارکت‌پلیس هوشمند B2C/B2B2C/B2B، تهران + یک شهر دوم؛ ۵ پرتال (مشتری، تأمین‌کننده، سازمان، ادمین، لجستیک)، لایهٔ کامل حسابداری، لجستیک چندحالته.
- تصمیم‌ها: modular monolith؛ حسابداری دوطرفه (غیرقابل مذاکره)؛ fraud scoring ایستا؛ OTP ایمیلی برای 2FA؛ اعتبار پیش‌پرداخت سازمان (پلتفرم اعتبار نمی‌دهد)؛ Python/FastAPI؛ تسویهٔ هفتگی تأمین‌کننده؛ ۱۰ هفته.
- استک: FastAPI، SQLAlchemy، PostgreSQL، Redis، Next.js + TS + Tailwind، Elasticsearch، Docker Compose.
- قدم بعد: اجرای end-to-end محلی، ۴–۱۰ تأمین‌کنندهٔ آزمایشی + یک سازمان آزمایشی در تهران.
