# پک‌ساز — گام ۱ پیاده‌سازی طرح Stitch (۲۶ آبان ۱۴۰۵)

منبع طرح: Stitch screen 35 «پک‌ساز هوشمند سازمانی» (شاخه‌ی `design/stitch-export-2026-11-16`، فایل `docs/design/stitch/screens/35-70d99ab4.html`).

## اصل محتوایی (تأکید کاربر)
پک‌های شصت‌آنلاین **هدیه نیستند**؛ عمدتاً پک‌های **معیشتی و مناسبتی (یلدا، نوروز، رمضان، فرهنگی…)** هستند که به‌صورت **عمده** توسط سازمان‌ها و مجموعه‌ها سفارش و به پرسنل داده می‌شوند.
طرح Stitch نمونه‌های «هدیه/قهوه/ماگ» دارد؛ در پیاده‌سازی فقط ساختار (چیپ‌های سریع، مراحل، بودجه) گرفته شد، نه محتوای هدیه‌ای.

## تغییرات این شاخه (`feat/pack-builder-stitch-2026-11-17`)
- `BudgetBuilder.tsx`: چیپ‌های سریع نوع پک (معیشتی، رمضان، نوروز، یلدا، رفاهی)، تعداد پک (۵۰ تا ۱۰۰۰) و بودجه هر پک (۱ تا ۵ میلیون تومان). همان API واقعی `/storefront/pack-builder`؛ بدون داده‌ی ساختگی.
- `PackStudio.tsx`: متن معرفی به «پک‌های معیشتی و مناسبتی · سفارش عمده سازمان‌ها»؛ ترتیب گروه‌ها: معیشتی، مناسبتی، سازمانی، هدیه.
- `PackBuilder.tsx` و `PackBuilderInteractive.tsx` (صفحه‌ی خانه) **دست نخورده‌اند**.
