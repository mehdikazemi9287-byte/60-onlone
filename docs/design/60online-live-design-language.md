## الگوهای صفحه خانه
هدر سفید (لوگو، جستجوی گرد، ورود اعضا، سبد) + نوار منو (دسته‌بندی کالاها، خرید سازمانی، پک‌ساز، هدیه کارکنان، غرفه‌ها، شبکه فروشگاه‌ها، وامبی، در شصت‌آنلاین بفروشید، نشان 60AI) → بنر دوتکه → ردیف آیکون خدمات گرد → نوار نارنجی «قیمت سازمانی» با کارت محصول و «قیمت با استعلام» → کارت‌های دسته پاستلی → بلوک پک‌ساز «بودجه یا نیازت را بگو؛ پک مناسب بساز» → غرفه‌ها و برندها.

## الگوی پک‌ساز فعلی
هیرو نعنایی «از یک ترکیب خوب، یک پک مناسب بسازید» → استپر ۴ مرحله (انتخاب روش، ساخت پک، بررسی، خرید/استعلام) → سه کارت روش (پک آماده، بر اساس بودجه، انتخاب دستی) → فیلترها (همه، خانه و خانواده، هدیه، مناسبت، سازمانی و کارکنان) → کارت پک (تصاویر اقلام، تعداد نوع کالا، حداقل تعداد، «استعلام قیمت»، مقایسه، «مشاهده و شخصی‌سازی»). حالت دستی: کاتالوگ واقعی + «خلاصه پک شما» چسبان کنار صفحه.

## قاعده برای طرح‌های جدید
طرح‌های جدید پک‌ساز باید ادامه همین زبان باشند (نه سبک جدید): همین لوگو، همین آبی/سرمه‌ای، همین استپر و کارت‌ها؛ فقط بخش‌های تازه (دستیار، مراسم، خیریه، عمده/ستاد، حمل) اضافه شوند.
