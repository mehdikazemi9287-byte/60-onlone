- فیلتر دسته‌ها: همه، معیشتی و ارزاق، مناسبت‌ها و نذورات، فرهنگی و مدارس، هدایای فاخر، سازمانی و کارکنان، هتل و پذیرایی، خیریه — با شمارش واقعی؛ دستهٔ خالی حالت خالی صادقانه دارد.
- کارت پک یکسان: تصویر با نسبت ثابت ۴:۳ فقط از عکس واقعی اقلام (با کنترل کیفیت موجود)، نام، تعداد قلم، حداقل سفارش، قیمت واقعی یا «قیمت پس از استعلام»، دکمهٔ اصلی سرمه‌ای «انتخاب برای استعلام» و دکمهٔ خط‌دار «مشاهده و شخصی‌سازی»؛ ۳ کارت در ردیف دسکتاپ. نشان نارنجی «قیمت سازمانی» فقط وقتی backend کانال `organization` را برای پک برگردانده باشد.
- خلاصهٔ چسبان پک (دسکتاپ، ستون ۴ از ۱۲) و نوار پایین چسبان (موبایل، بالای ناوبری پایین سایت). جمع کل فقط وقتی قیمت واقعی پک وجود دارد؛ وگرنه «پس از استعلام». حداقل سفارش پک رعایت می‌شود.

- بخش‌های کم‌اولویت در آکاردئون بسته: سامانه ستاد، ارسال و لجستیک، خیریه و CSR، کاتالوگ PDF — با برچسب «به‌زودی» و بدون فرم یا عدد ساختگی. تنها عدد نمایش‌داده‌شده وزن اقلام ثبت‌شدهٔ پک انتخابی × تعداد است.

## مغایرت‌های frontend ↔ backend (قاعدهٔ ۸)
- `PackSummary.price_minor` در backend فقط برای پک قابل‌خرید (`purchasable`) مقدار دارد؛ شاخهٔ «برآورد» در `PackCard.tsx` برای `quote_only` عملاً اجرا نمی‌شود (بی‌خطر، فقط کد مرده).
- backend فیلدهای `provenance` (پک) و `family_id`/`category_id` (اقلام) را هم برمی‌گرداند که در type فرانت نیست؛ `allowed_channels` در backend همیشه هست ولی در type اختیاری است.
- `food_weight_g` در backend جمع وزن همهٔ اقلام دارای وزن است، نه فقط خوراکی؛ برچسب فرانت «وزن مواد غذایی» است.
- API برای ستاد، برآورد لجستیک، تحویل به خیریه، کاتالوگ PDF/آرشیو، بسته‌بندی و چاپ لوگو وجود ندارد (در UI «به‌زودی»).
- پیوند `?mode=edit` در کد موجود است ولی PackStudio آن را پردازش نمی‌کند (رفتار قبلی هم همین بود).

## تغییر رفتاری که باید بدانید
- قبلاً اگر پیش‌نویس ذخیره‌شده داشتید، ویرایشگر خودکار باز می‌شد و صفحهٔ اصلی دیده نمی‌شد. اکنون صفحهٔ جدید نمایش داده می‌شود و «ادامه پک ذخیره‌شده» در خلاصه (و در موبایل بالای پک‌ها) هست. انتخاب پک جدید با وجود پیش‌نویس همچنان هشدار «جایگزینی / حفظ» می‌دهد؛ «حفظ» پیش‌نویس قبلی را باز می‌کند.
- استپر (`Steps`) ظاهر جدید گرفت و در صفحهٔ `/packs/[slug]` هم استفاده می‌شود.
