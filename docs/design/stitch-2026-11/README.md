## چه چیزی عوض شد (فقط ظاهر؛ نشانه‌گذاری، نقش‌ها و برچسب‌های دسترس‌پذیری دست‌نخورده)
- `frontend/tailwind.config.ts`: توکن‌های `ink/line/canvas`، مقیاس `neutral` و `primary` تازه، `white` واقعی، سایه‌های مینیمال
- `frontend/src/app/globals.css`: لایهٔ «Minimal Chic» در انتهای فایل — یک‌جا همهٔ کارت‌ها، فرم‌ها، هیروها، جدول‌ها و نوار پایین موبایل را تنظیم می‌کند
- هدر و فوتر جدید؛ نوار تب پایین موبایل مثل اپ: خانه، دسته‌بندی، سبد (با شمارنده)، سفارش‌ها، حساب — با نشانگر صفحهٔ فعال و safe-area
- PWA: `theme_color` سفید، زمینهٔ اپ `#F7F7F5`، `overscroll` در حالت نصب‌شده
- کامپوننت‌های مشترک: `ui/Button`، `ui/Badge`، `commerce/ui`، `product/ProductCard`
- پوسته‌ها: پنل سازمانی (سایدبار و هیروی سفید به‌جای سرمه‌ای)، پیشخوان مدیریت (آیتم فعال pill سرمه‌ای)، ماژول تدارکات
- جایگزینی رنگ‌های آبی/خاکستری پراکندهٔ قدیمی (`#034EA2`، `#1677FF`، `#E3E8EF` و …) با توکن‌ها در ۲۰ فایل
- دکمه‌های اصلی پراکنده (۳۹ مورد در ۲۵ فایل) → pill سرمه‌ای
- صفحهٔ اول: فقط رنگ و سطح‌ها (هیروی سرمه‌ای تخت، نوار «قیمت سازمانی» سفید به‌جای نارنجی، کاشی‌های خنثی). ساختار و متن تغییری نکرد.

## مانده‌ها و گام بعد
1. **دیپلوی تولید انجام نشده**: از این محیط به سرور (60online.ir) دسترسی SSH نیست. دستور روی سرور:
   ```bash
   cd <مسیر مخزن روی سرور> && git fetch && git checkout design/stitch-minimal-2026-11   # یا بعد از merge: main
   cd deploy && docker compose -f docker-compose.prod.yml exec backup /bin/sh /backup.sh
   docker compose -f docker-compose.prod.yml up -d --build frontend
   ```
   فقط فرانت تغییر کرده؛ هیچ مهاجرت دیتابیسی نیست.
2. بررسی بصری PR توسط هم‌تیمی که موازی روی 60Online کار می‌کند، پیش از merge.
3. وامبی: رفع سرریز ۳px در Figma/مخزن جدای وامبی.
