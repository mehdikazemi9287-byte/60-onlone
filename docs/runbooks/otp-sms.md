# ورود با کد پیامکی (OTP) — راه‌اندازی روی سرور

| متغیر | مقدار |
|---|---|
| `SMS_PROVIDER` | `kavenegar` (در توسعه/تست: `console`، پیش‌فرض) |
| `KAVENEGAR_API_KEY` | کلید API پنل کاوه‌نگار |
| `KAVENEGAR_TEMPLATE` | نام الگوی «تأیید» در پنل؛ متن نمونه: `کد ورود شصت‌آنلاین: %token` |
| `KAVENEGAR_SENDER` | شمارهٔ خط اختصاصی برای پیامک متنی (خلاصهٔ هشدار قیمت). بدون آن پیامک هشدار ارسال نمی‌شود و فقط اعلان داخل سایت می‌ماند. |
| `PRICE_ALERT_DAILY_SMS_CAP` | سقف کلی پیامک‌های هشدار قیمت در روز (پیش‌فرض ۵۰۰). |

- در `APP_ENV=production` با فرستندهٔ `console` هیچ کدی صادر نمی‌شود (خطای ۵۰۳ `sms_unavailable`).
- کد ۶ رقمی است، ۲ دقیقه اعتبار دارد و فقط هش HMAC آن ذخیره می‌شود. پس از ۵ تلاش اشتباه قفل می‌شود.
- محدودیت‌ها: برای هر شماره یک درخواست در ۶۰ ثانیه و ۵ در ساعت؛ برای هر IP بیست درخواست در ساعت.
- ورود با کد فقط به `users.phone_verified` اعتماد می‌کند. شمارهٔ ثبت‌شده هنگام ثبت‌نام خودکار وصل نمی‌شود؛ کاربر از داخل حسابش با `/api/v1/auth/phone/request` و `/phone/verify` آن را تأیید می‌کند.
- شمارهٔ ناشناس پس از تأیید کد یک حساب «مشتری» می‌سازد و نام کاربر را می‌خواهد.
- API‌ها: `POST /api/v1/auth/otp/request {phone}` و `POST /api/v1/auth/otp/verify {phone, code, full_name?}`.
- اگر سرور پشت پراکسی است، `client_ip` باید IP واقعی کاربر را بدهد؛ وگرنه سقف هر IP برای همه مشترک می‌شود.
