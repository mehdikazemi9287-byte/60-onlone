# درگاه‌های نرم‌افزارهای مالی و سامانهٔ مودیان (فاز 5B)

## مدل استاندارد خروجی
`app/services/finance_export_service.py` برای یک دوره و یک موجودیت (پلتفرم، فروشنده، سازمان خریدار) اسناد را در قالب JSON استاندارد (`60online.finance-export/1`) می‌سازد:
فاکتور فروش فروشنده، فاکتور کارمزد ۶۰آنلاین، فاکتور خرید سازمان، دریافت/پرداخت، تسویه با فروشنده و صورت‌حساب اعتباری.
همهٔ مبالغ ریال صحیح است؛ مالیات هر ردیف با نرخ `tax_service` (کف) و جمع سربرگ دقیقاً برابر جمع ردیف‌ها؛ هر سند حسابداری تراز (بدهکار = بستانکار).
فرض: قیمت ردیف‌های فروشنده و کارمزد بدون مالیات است و ارزش افزوده روی آن افزوده می‌شود.

## نگاشت حساب‌ها
جدول `finance_account_mappings` — کلیدهای ثابت (`revenue`، `commission_income`، `vat_payable`، `seller_payable`، `receivable`، `bank`، ...) به کد حساب هر نرم‌افزار. ردیف‌های `DEFAULT` پیش‌فرض هستند و برای هر درگاه قابل بازنویسی‌اند.

## قالب‌ها
`SEPIDAR` (اکسل/CSV سند و فاکتور)، `HAMKARAN`/`RAHKARAN` (JSON یا XML ورود سند؛ ارسال با transport تزریقی)، `MAHAK` (CSV)، `HOLOO` (اکسل/CSV)، `CSV`، `EXCEL`، `JSON`.
تاریخ‌ها در قالب‌های ایرانی شمسی‌اند. ستون‌ها با قالب رایج هر نرم‌افزار تنظیم شده؛ پیش از بهره‌برداری با قالب ورود مشتری تطبیق دهید.
خروجی قطعی است: پارامتر یکسان ← فایل و sha256 یکسان (همان job برگردانده می‌شود).

## سامانهٔ مودیان
`app/services/moadian_invoice_service.py`: هر فروشنده صورتحساب کالای خود را صادر می‌کند (`fo:{id}`)؛ ۶۰آنلاین فقط صورتحساب کارمزد/خدمات (`commission:{supplier}:{start}:{end}`).
شمارهٔ مالیاتی (taxid) طبق SDK سازمان امور مالیاتی (شناسه حافظه + روز + سریال + رقم کنترل Verhoeff) — **پیش از تولید با SDK رسمی تطبیق شود**؛ قابل جایگزینی است.
امضا و ارسال به‌صورت رابط تزریقی است (بدون کلید واقعی). کد واحد (`DEFAULT_UNIT`) و شناسهٔ کالا/خدمت (`sstid_resolver`) باید از فهرست‌های رسمی تأمین شوند؛ نبود sstid هشدار می‌دهد و مانع ارسال است.

## API
- `/api/v1/admin/finance-exports` (ایجاد/فهرست/دانلود)، `/api/v1/admin/finance-formats`
- `/api/v1/admin/finance-mappings` (CRUD)
- `/api/v1/admin/moadian/fiscal-ids|preview|documents|documents/<id>/mark-submitted`
- `/api/v1/supplier/finance-exports` و `/api/v1/supplier/moadian/documents` — فقط دادهٔ خود فروشنده
