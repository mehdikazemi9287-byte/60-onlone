# وامبی (Vambi)

موتور جستجو و مقایسهٔ قیمت **درون اکوسیستم** شصت آنلاین. فقط فروشنده‌های طرف قرارداد شصت آنلاین را مقایسه می‌کند، نه کل بازار، و برای ارزان شدن یا موجود شدن کالا هشدار می‌دهد.

- دامنه: `vambi.ir`
- **کد:** در ریپوی [`60-onlone`](https://github.com/mehdikazemi9287-byte/60-onlone) است، چون حساب کاربری، کالاها، قیمت‌ها و فروشنده‌ها با شصت آنلاین مشترک‌اند. فهرست دقیق فایل‌های وامبی در [docs/TECHNICAL.md](docs/TECHNICAL.md) است.
- **این ریپو** جای برنامه، گزارش پیشرفت، چک‌لیست راه‌اندازی، برنامهٔ اطلاع‌رسانی و Issueهای وامبی است.
