# وامبی (Vambi)

موتور جستجو و مقایسهٔ قیمت **درون اکوسیستم** شصت آنلاین. فقط فروشنده‌های طرف قرارداد شصت آنلاین را مقایسه می‌کند، نه کل بازار، و برای ارزان شدن یا موجود شدن کالا هشدار می‌دهد.

- دامنه: `vambi.ir`
- **این ریپو خانهٔ مستقل وامبی است:** فرانت وامبی در [`web/`](web/) یک برنامهٔ جدا (Next.js) با هویت، دامنه، رنگ و فونت خودش است و هیچ صفحه یا قالبی از شصت آنلاین در آن نیست.
- **داده:** وامبی فعلاً بک‌اند جدا ندارد. کالا، فروشنده، قیمت و حساب کاربری را از API اکوسیستم شصت آنلاین می‌خواند (ریپوی [`60-onlone`](https://github.com/mehdikazemi9287-byte/60-onlone)). ورود هم با حساب شصت آنلاین است.

## صفحه‌ها
| آدرس | چه چیزی |
| --- | --- |
| `/` | جستجو و مقایسهٔ فروشنده‌ها |
| `/about` | وامبی چیست |
| `/alerts` | کالاهای زیر نظر و هشدار قیمت |
| `/sso/callback` | پایان ورود با حساب شصت آنلاین |

## اجرا
```
cd web
cp .env.example .env.local   # VAMBI_API_ORIGIN و NEXT_PUBLIC_MAIN_SITE
npm ci && npm run build && npm start
```
با Docker: `docker build -t vambi-web web`
